# Real-Part DSL Data (RQ4)

Conveyor equipment part family: shaft · roller · pulley · sprocket · bracket · frame

## What goes here

1. Formalize the parametric models of the above parts as DSL
   (corresponds to `dsl/grammar.md`)
2. Collect real variant-design history as edit pairs
   — length, diameter, hole-position changes
3. Link to the confirmed labels & order history from the prior part-recognition project

## Important

- Confidential drawings stay on the intranet
- Targets are judged only on the held-out real-part set
- If data volume is insufficient, supplement with template-based synthetic
  augmentation, but synthetic data does not count toward targets (risk R4)
