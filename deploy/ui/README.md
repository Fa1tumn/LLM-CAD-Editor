# Review UI (HITL)

Approve/reject interface, corresponding to the "interface" layer of the
system-composition table.

- natural-language edit input
- before-after 3D diff view
- approve · reject buttons
- review labels recycle into training data

Only the ~20% the four-stage verification loop is unsure about enters this
queue (G5: auto-confirm ≥80%). Can be prototyped quickly with streamlit
(M10 pilot).
